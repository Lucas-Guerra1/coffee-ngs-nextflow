# coffee-ngs-nextflow

Reproducible **NGS → SNP → phylogeny** pipeline built with **Nextflow**, designed as a plant genomics bioinformatics portfolio project.

## Overview

This repository contains a minimal, reproducible workflow for:

- Quality control of paired-end NGS reads  
- Read mapping to a reference genome  
- SNP calling and filtering  
- Generation of SNP alignment  
- Phylogenetic tree inference  

The goal is to demonstrate **bioinformatics pipeline design, reproducibility, and data analysis skills** relevant for research and remote scientific work.

## Technologies

- Nextflow  
- BWA  
- SAMtools  
- GATK  
- BCFtools  
- FastTree  
- Python / R
